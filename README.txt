# Adyant Shukla — Equity Research Portfolio

A static portfolio website featuring Apple, Microsoft, and NVIDIA equity research.

## Files
- index.html — homepage
- apple.html — Apple report page
- microsoft.html — Microsoft report page
- nvidia.html — NVIDIA report page
- styles.css — site styling
- script.js — small navigation enhancement

## Publish
This is a static website. Upload the folder to any static hosting service or open index.html locally.
